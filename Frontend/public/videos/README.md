# Video Assets

This directory contains video assets for the application.

## Required Videos

### hero-video.mp4
- **Purpose**: Main hero section background video on landing page
- **Recommended specs**:
  - Resolution: 1920x1080 (Full HD) or higher
  - Format: MP4 (H.264 codec)
  - Duration: 10-30 seconds (loops automatically)
  - File size: Keep under 5MB for optimal loading
  - Aspect ratio: 16:9

### promo-video.mp4
- **Purpose**: Promotional video in the deals/promotional section
- **Recommended specs**:
  - Resolution: 1280x720 (HD) or higher
  - Format: MP4 (H.264 codec)
  - Duration: 15-45 seconds
  - File size: Keep under 10MB
  - Aspect ratio: 16:9

## Placeholder Files

Until you add actual video files, the components will display placeholder messages.
To replace placeholders:

1. Add your video files to this directory
2. Name them exactly as listed above (hero-video.mp4, promo-video.mp4)
3. The components will automatically load them

## Optimization Tips

- Use tools like HandBrake or FFmpeg to compress videos
- Consider using video hosting services (YouTube, Vimeo) for larger videos
- Add poster images for better loading experience
- Test on mobile devices for performance
